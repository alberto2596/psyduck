TEALIUM

Cómo proceder a guardar una nueva versión en Tealium

Fechas de ejemplo: 21/10/2026 (objetivo) y 04/11/2026 (siguiente)
🔍 Paso 0 (Comprobación previa): Lo primero que hay que mirar es si hay RC (Release Candidate) para la fecha que yo quiero (ej. 21/10/2026) y para la siguiente release (ej. 04/11/2026).
🧭 Asistente interactivo: ¿Qué hay creado ahora mismo en Tealium?
1. ¿Hay RC para la fecha que quieres (21/10/2026)?
2. ¿Hay RC para la siguiente release (04/11/2026)?
Escenario 1 · Hay RC de ambos días

Existe RC tanto del 21/10/2026 como del 04/11/2026

  • 1. De dónde partirPartimos de la del 21/10/2026 (si queremos preparar la del 21).
  • 2. Dónde guardarGuardamos en el mismo sitio donde esté guardada la del 21/10/2026.
  • 3. Título / NomenclaturaRespetando el nombre que ya tiene la versión.
  • 4. Comentario / DescripciónAñadir con un + nuestro cambio en el comentario.
Escenario 2 · No hay RC para la siguiente

Hay RC del 21/10/2026, pero NO hay RC para el 04/11/2026

  • 1. De dónde partirPartimos de la del 21/10/2026.
  • 2. Dónde guardarGuardaremos en DEV / QA.
  • 3. Título / NomenclaturaRespetando nomenclatura.
  • 4. Comentario / DescripciónAñadir un + con nuestro cambio en la descripción.
Escenario 3 · No hay ninguna RC

No existe ninguna RC creada todavía

  • 1. De dónde partirPartimos directamente de PROD.
  • 2. Dónde guardarGuardamos nuestra versión en DEV / QA.
  • 3. Título / NomenclaturaSubiendo un número al título respecto a PROD.
  • 4. Comentario / DescripciónAñadir el cambio al comentario.
